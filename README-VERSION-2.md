## 3. Why `tailwind.config.ts` goes away

`package.json` has `tailwindcss ^4.0.14` + `@tailwindcss/postcss`, and
`globals.css` uses `@import "tailwindcss"`. **Tailwind v4 does not read
`tailwind.config.ts` unless you explicitly `@config` it**, so all of this was inert:

- `darkMode: "class"` — never applied. In v4 `dark:` defaults to
  `prefers-color-scheme`, which is why `dark:` utilities didn't follow the
  `.dark` class and every component hand-rolled
  `theme === "light" ? "bg-gray-50" : "bg-gray-900"`.
- `colors.bgDarkSecondary: ""`, `fontDarkSecondary: ""` etc. — invalid empty values.
- `fontFamily` Poppins / Merriweather / Fira Code — never loaded; `layout.tsx`
  actually loaded Geist.

`globals.css` now declares `@custom-variant dark (&:where(.dark, .dark *))` and real
tokens in `@theme inline`, so `dark:` works and the ternaries are gone.

## 8. Fixes in this revision

**Invisible button labels (CV button, email button).**
`globals.css` had a bare `a { color: var(--accent) }` rule. Tailwind v4 puts its
utilities in `@layer utilities`, and **unlayered CSS always beats layered CSS** —
so that one rule overrode `text-accent-contrast` on every link, painting accent
text on an accent background. The label only appeared on hover because
`a:hover { color: var(--ink) }` swapped it. Base rules now sit inside
`@layer base`, and the two button links also carry `!text-` for belt and braces.
If you ever add a global element rule to `globals.css`, put it in `@layer base`.

**`\u00b7` / `\u2014` / `\u2197` printing as literal text.**
Those escapes were sitting in JSX *text nodes*, where JSX does not interpret
`\uXXXX`. Replaced with the real characters (`·` `—` `↗` `↑`) throughout.

**Contact form hidden, not deleted.**
`SHOW_CONTACT_FORM = false` in `data/profile.ts`. The full form (state, handler,
`/api/send-email` call, markup) is still in `ReachOutSection.tsx` behind the flag,
and the Reach out panel drops to a single column while it is off. Flip the flag to
bring it back. Socials now sit in a 3-across grid to fill the freed width.

**Animation.**
Your left-to-right entrance is kept, but rebuilt in `styles/animation.css`:
- `reveal-left` — the original left→right slide, softened (28px, 700ms, ease-out curve).
- `reveal-up` — an 18px rise, used for card grids where a sideways slide reads oddly.
- `reveal-stagger` — cards in a grid come in 80ms apart instead of all at once.
- `draw-rule` — the accent underline under each section heading draws itself out
  from the left, echoing the purple rule from your v1.

`SlideInTextAnimation.tsx` now reveals **once** (it previously re-hid elements on
every scroll pass, which caused flicker when scrolling back up) and no longer
disables itself on mobile. Everything is disabled under
`prefers-reduced-motion: reduce`.
